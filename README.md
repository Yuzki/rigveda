# rigveda

Texts and scripts for the Rigveda.

## Research-book indexes moved

The scholarly back-of-book index TSVs formerly maintained in `reference/` have been moved to **[Yuzki/veda-book-index](https://github.com/Yuzki/veda-book-index)**. The original five populated TSV files are retained here as legacy copies for compatibility; maintain and extend indexes only in the new repository.

See [reference/README.md](reference/README.md) for a file-by-file migration map. Other reference texts in this repository have not been moved.
